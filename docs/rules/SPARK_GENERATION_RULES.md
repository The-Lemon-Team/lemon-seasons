# 📋 Правила генерации новостных заметок Spark

> **Статус:** Обязательный стандарт для всех AI-агентов, Gemini Gems и внешних скриптов генерации контента для каталога `spark/`.  
> **Шаблон заметки:** `docs/templates/gem-news-template.md`  
> **Шаблон канала:** `docs/templates/spark-channel-template.md`

---


## 1. 📅 Правило синхронизации дат (Каноническая дата)

Каждая новость создается под конкретный выпуск ленты (утренний или вечерний слот). Дата в имени файла и дата внутри метаданных обязаны строго совпадать.

### Спецификация:
1. **Имя файла:**
   - Формат: `ДД.ММ.ГГ - <Название статьи без спецсимволов>.md`
   - Пример: `25.10.26 - Релиз Claude Haiku 5.5 от Anthropic.md`
   - Двузначный год `26` соответствует `2026` году.
2. **Поле `start_date` во Frontmatter:**
   - Формат: Строка ISO 8601 — `ГГГГ-ММ-ДДTHH:mm:ss.000Z`
   - Пример: `"2026-10-25T07:15:00.000Z"`
   - **СТРОГИЙ ЗАПРЕТ РАССИНХРОНА:** Если файл датирован `25.10.26`, в `start_date` **запрещено** указывать вчерашнюю дату (например `2026-10-24`), даже если новость на сайте-первоисточнике появилась вечером накануне. Вся сводка за 25-е число должна иметь `start_date: "2026-10-25T..."`.
3. **Поле `end_date`:**
   - Для точечных новостей (`type: "EVENT"`) — всегда `null`.
   - Для сводных дайджестов (`type: "PERIOD"`) — ISO 8601 дата окончания охватываемого периода.

---


## 2. 🏷️ Правило тегов и лейблов

1. **Формат записи тегов:**
   - Теги во frontmatter перечисляются списком строк в кавычках или без:
     ```yaml
     tags:
       - "ai"
       - "нейросети"
       - "llm"
       - "агенты"
     ```
   - Символ `#` указывать **не нужно** (система нормализует теги автоматически).
   - Не оставлять пустых тегов `- ""` в итоговом файле.
2. **Лейбл дайджеста (`jmdaily`) — ЗАПРЕТ ДЛЯ АВТОГЕНЕРАЦИИ:**
   - Тег `jmdaily` зарезервирован **исключительно для ручной аналитической работы администратора**.
   - Внешним генераторам, AI-агентам и Gemini Gems **строго запрещено** автоматически проставлять тег `jmdaily`.

---


## 3. 🧹 Чистый Frontmatter (Разрешенные и запрещенные поля)

Внешний агент обязан формировать только чистый пользовательский frontmatter. Системные поля рассчитываются инжектором Lenta автоматически.

### ✅ Разрешенные поля:
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `title` | `string` | Заголовок статьи (в кавычках) |
| `type` | `"EVENT" \| "PERIOD" \| "THREAD"` | Тип записи (обычно `"EVENT"`) |
| `start_date` | `string` (ISO 8601) | Точная дата новости, согласованная с именем файла |
| `end_date` | `null \| string` | `null` для EVENT |
| `tags` | `string[]` | Теги темы, технологий и лейбл `jmdaily` |
| `links` | `Array<{ url, title, is_source }>` | Первоисточники с атрибутом `is_source: true` |
| `cover_image` | `string` | URL изображения или пустая строка `""` |
| `podcast_audio` | `string` | Имя аудиофайла подкаста или `""` |
| `published` | `boolean` | `false` (черновик) или `true` |
| `icon` | `string` | Emoji (например: `"🤖"`, `"⚡"`, `"💡"`, `"🛡️"`) |
| `resonance_score` | `number` (0-100) | Оценка резонанса события |

### ❌ Запрещенные поля (НЕ добавлять в Gem):
- `feed`, `process`, `taxonomy`, `folders`, `primary_folder`, `lenta_id`, `updated_at`, `deleted`.

---


## 4. 📐 Оформление и типографика Markdown

1. **Отступы:**
   - После закрывающего разделителя frontmatter `---` всегда выдерживаются **две пустые строки** перед заголовком первого уровня `# {{title}}`.
   - Между секциями с горизонтальной чертой `---` перед заголовками `## ...` выдерживается отступ в две пустые строки.
2. **Обязательные секции заметки:**
   - `## 📌 Суть события` — кратко: кто, что, где, когда (3–5 предложений).
   - `## 🔎 Детали и контекст` — факты, цифры, цитаты, технические подробности.
   - `## 🧭 Аналитическая оценка` — влияние на индустрию, последствия, риски.
   - `## 🔗 Связанные записи` — вики-ссылки Obsidian при наличии (например `[[Другая заметка]]`).

---


## 5. 🤖 Готовая инструкция (Системный промпт) для агентов и Gemini Gems

При настройке любого внешнего AI-агента или Gemini Gem скопируйте следующий блок в поле «Инструкции»:

```text
Ты — автономный редактор новостей Spark (Project Lenta).
При генерации Markdown-заметок ты строго следуешь стандарту:

1. Имя файла: ВСЕГДА в формате "ДД.ММ.ГГ - <Название>.md" (например: 25.10.26 - Релиз Claude Haiku 5.5 от Anthropic.md).
2. Дата start_date: ОБЯЗАНА строго соответствовать дате в имени файла: если в имени 25.10.26, то start_date: "2026-10-25T07:15:00.000Z". Запрещено ставить вчерашнюю дату (2026-10-24)!
3. Теги: массив tags должен содержать тему канала (например: tags: ["ai", "нейросети", "llm"]). НЕ добавлять тег "jmdaily" (он зарезервирован под ручную аналитику). Записывать без символа #.
4. Frontmatter: использовать только поля title, type, start_date, end_date, tags, links, cover_image, podcast_audio, published, icon, resonance_score. Не добавлять поля feed, taxonomy, lenta_id.
5. Структура текста:
   - Две пустые строки после frontmatter.
   - Заголовок # <Заголовок>
   - Секции: ## 📌 Суть события, ## 🔎 Детали и контекст, ## 🧭 Аналитическая оценка, ## 🔗 Связанные записи.
```
