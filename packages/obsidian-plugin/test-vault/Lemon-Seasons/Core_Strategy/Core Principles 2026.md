# Core Strategic Principles 2026: Privacy-First & Distributed Ownership

### The Three Non-Negotiable Pillars
1. **User Owns Their Data**: Notes live as plain text Markdown on the local filesystem.
2. **Privacy by Design**: Private vaults are physically partitioned by container IDs and never broadcast.
3. **Frictionless Sync**: Delta-based synchronization with deterministic conflict resolution.
