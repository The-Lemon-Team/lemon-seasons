# Mental Models for Chronological Information Systems

### Linear vs Branching Time

Most calendar applications treat time as empty slots to fill. Project Lenta treats time as an anchor for evolving documents.

- Events have durations, milestones have moments, releases have cascading dependencies.
- Organizing by both semantic taxonomy and physical virtual folders mirrors how human memory works.
